# Support

- **Bug reports and feature requests**: open a GitHub issue using the templates in
  [`.github/ISSUE_TEMPLATE/`](.github/ISSUE_TEMPLATE/).
- **Questions about using Africa Local**: open a GitHub Discussion (or an issue, if Discussions
  are not yet enabled on this repository) - there is no separate chat channel yet.
- **Requesting a new provider or country**: use the "Provider request" issue template, then see
  [`providers/_template/CONTRIBUTING.md`](providers/_template/CONTRIBUTING.md) if you'd like to
  build it yourself.
- **Security vulnerabilities**: do not open a public issue - see [SECURITY.md](SECURITY.md).

This is an early-stage, community-maintained project (see [GOVERNANCE.md](GOVERNANCE.md)) with no
paid support tier or SLA.
