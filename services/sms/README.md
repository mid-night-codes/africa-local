# services/sms (planned - Phase 5)

Not implemented. Would emulate SMS gateway APIs: sending a message, delivery report callbacks
(delivered/failed/expired), and inbound-SMS webhooks for two-way flows. See
[`services/README.md`](../README.md) for why this isn't built yet and what implementing it would
require (an RFC extending `specs/provider-manifest.schema.json#category`).
