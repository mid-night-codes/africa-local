# docs/concepts

The canonical vocabulary and canonical concepts (Provider, Capability, Payment, Scenario,
Callback, Event, Status, Correlation ID, etc.) are defined in
[`specs/service-contract.md`](../../specs/service-contract.md), and the payment state machine in
[`specs/state-machines/payment-lifecycle.md`](../../specs/state-machines/payment-lifecycle.md).
This directory is reserved for conceptual explainers that go beyond the spec-level definition
(e.g. "why callbacks are modeled the way they are" for someone new to mobile-money integration
patterns). Empty in v0.1.
