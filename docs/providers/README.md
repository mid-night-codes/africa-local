# docs/providers

For how providers work and how to add one, see [`providers/README.md`](../../providers/README.md)
and [`providers/_template/`](../../providers/_template/) - that's where the mechanics live, right
next to the code and YAML they describe (per `AGENTS.md`'s "context lives close to where it
applies" principle). This directory is reserved for cross-provider narrative docs (e.g. a survey
of mobile-money integration patterns across countries) that don't belong inside any one provider's
own README. Empty in v0.1.
